# potlerh
Web page for generating wiremesh obj files

## Functionalities
- move around
    -distance: the scrollwheel changes the distance to the object
    -rotation: pressing the scrollwheel will rotate the object around the camera
- download: download the obj file with the download button
- read: read the provided text after pressing enter if it is in the correct formatting

## Commands in normal mode
### :clear
Remove all vertices

### :cube
Generate cube

### :rot
Start rotation with default speed

### :srot
Stop rotation

### :initrot
Set rotation to default

### xangle=
Set yangle

### yangle=
Set yangle

### += xangle
Add following angle to xangle

### += yangle
Add following angle to yangle

### ./[file]
open file

### :xrot
yanglev=rotationspeed

### :yrot
yanglev=rotationspeed

### :drawv
Toggle draw-vertices mode

### :ccld
Generate cilinder

### :gsphere
Generate sphere

### :d
Set distance to default

### :init
Set initial conditions

### :interact
Set interact mode to interact

### :circle
generate circunference

### :showi
Toggle show-index mode
